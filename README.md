🔗 KBSI GO

Instant Sync. No Wire.

KBSI GO is a device-to-device sharing web application designed for quick text synchronization and file transfers.

Devices can connect on the same Wi-Fi network or pair using a code across networks.

✨ Features

- ⚡ Live text synchronization
- 📁 File transfer between devices
- 📡 Same-Wi-Fi device connection
- 🔢 Code-based pairing
- 🔐 No account required
- 🚫 No installation required
- 🗑️ Temporary data handling with automatic deletion after 24 hours

🎯 Purpose

KBSI GO was created to provide a simple way to exchange text and files between devices without requiring users to create an account.

🌐 Live Demo
